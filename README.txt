MacVault website
Files: index.html, style.css, script.js, 404.html (no build step, plain static site).

Deploy (free):
- Netlify Drop: go to app.netlify.com/drop and drag this whole folder onto the page.
- GitHub Pages: upload these files to a repository, then Settings > Pages > deploy from main branch.
- Cloudflare Pages: create a project and upload this folder.

Test locally: open index.html in a browser.
After deploying, send the link to make a QR code for it.
